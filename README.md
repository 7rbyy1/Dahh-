# دهاء (Dahaa)

لعبة ثقافية جماعية تفاعلية للجمعات والاستراحات — فريقان، 6 فئات، 36 سؤالاً، ومؤقت. بدون وسائل مساعدة: المعرفة وسرعة البديهة فقط.

موقع ثابت (HTML + CSS + JavaScript) بدون أي مكتبات أو خطوة بناء، جاهز للنشر على Vercel مباشرة.

## هيكلة المشروع

```
dahaa/
├── index.html            ← الصفحة الرئيسية (الشاشتان + النوافذ)
├── css/
│   └── style.css         ← الهوية البصرية (بيج دافئ / كريمي / ألوان ترابية)
├── js/
│   ├── questions.js      ← قائمة الفئات + بنك الأسئلة
│   └── app.js            ← منطق اللعبة (الاختيار، اللوحة، النقاط، المؤقت)
├── assets/
│   ├── logo.svg          ← لوجو مؤقت (استبدله بلوجو اللعبة)
│   ├── favicon.svg
│   └── posters/          ← بوسترات الفئات (انظر README داخل المجلد)
├── vercel.json
└── .gitignore
```

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً بسيطاً:

```bash
npx serve .
# أو
python3 -m http.server 8080
```

## الرفع على GitHub والنشر على Vercel

```bash
git init
git add .
git commit -m "Dahaa: initial release"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/dahaa.git
git push -u origin main
```

ثم في Vercel: **Add New → Project → Import** المستودع، واترك الإعدادات الافتراضية:
- Framework Preset: **Other**
- Build Command: (فارغ)
- Output Directory: (فارغ / الجذر)

## التخصيص

- **اللوجو:** ضع ملفك في `assets/` (مثلاً `logo.png`) وعدّل `src` في وسم `<img id="brandLogo">` داخل `index.html`. الارتفاع يُضبط تلقائياً (44px) من `.brand-logo` في `style.css`.
- **البوسترات:** ضع الصور في `assets/posters/` بالأسماء الموضحة هناك.
- **الأسئلة:** في `js/questions.js` — كل فئة لها 3 مستويات (200 / 400 / 600). أضف `{ q: "...", a: "..." }` لأي مستوى.
- **فئة جديدة:** أضفها إلى `DAHAA_CATEGORIES` وأضف أسئلتها بنفس `id` في `DAHAA_QUESTIONS`.
- **الألوان:** كلها متغيرات في أول `css/style.css` تحت `:root`.

## آلية عدم التكرار

كل سؤال يُفتح يُسجَّل في المتصفح (`localStorage`)، وفي القيم التالية تُسحب أسئلة لم تظهر بعد. عندما تنتهي أسئلة مستوى معيّن في فئة، يُعاد تدويرها تلقائياً. كلما أضفت أسئلة أكثر، طالت المدة قبل أي تكرار.

حالة القيم (النقاط، اللوحة، الدور) تُحفظ أيضاً، فلو أُعيد تحميل الصفحة بالخطأ تكمل من حيث توقفت.
